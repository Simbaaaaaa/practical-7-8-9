# Вариант 19 — Автомойка и детейлинг-центр

Стек: Python 3.11+, Django 4.2+, SQLite (через ORM), HTML/CSS/JavaScript.

## Установка (Windows)
```powershell
py -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
py manage.py makemigrations garage
py manage.py migrate
py manage.py seed_demo
py manage.py runserver
```
Откройте http://127.0.0.1:8000/

## Демо-пользователи
- Клиент: `client_demo` / `client12345`
- Мойщик: `washer_demo` / `washer12345`
- Администратор смены: `admin_demo` / `admin12345`

Создать администратора Django: `py manage.py createsuperuser`, панель `/admin/`.

## Логика варианта 19
- Цена и длительность услуги пересчитываются по коэффициентам типа кузова.
- Сервер автоматически назначает свободный бокс нужного типа.
- Пересекающиеся бронирования одного бокса запрещаются.
- Каждая шестая завершённая базовая мойка получает скидку 50%.
- Бронирование и обновление карты лояльности используют `transaction.atomic`.
- Роли: гость, клиент, мойщик, администратор смены, суперпользователь.

## Реализовано
Регистрация/вход/выход/смена пароля Django Auth; личный кабинет; CRUD автомобилей; записи; поиск, три фильтра, сортировка, пагинация 20; агрегированная статистика и график; fetch JSON для доступности боксов; фото автомобиля с проверкой типа/размера; CSV; email через консольный backend; Django Admin; демо-команда создаёт 30 записей и связанные данные.

`DEBUG=False` установлен по умолчанию. Перед публикацией задайте собственные `DJANGO_SECRET_KEY` и `DJANGO_ALLOWED_HOSTS`. Для локальной отладки можно временно включить `DJANGO_DEBUG=True`.

График загружает Chart.js с CDN. Добавьте свои скриншоты после запуска проекта. Тестовые пароли предназначены только для учебной демонстрации.
